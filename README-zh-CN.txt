休息一下 · Rest Guard 1.3.0
Windows / Steam《文明 VII》单人游戏。

右上角入口
入口接入游戏顶部系统栏最右端，按正常布局为原版按钮留出位置。
用游戏自带的回合图标、时间图标加数字显示：
  回合图标 5 / 时间图标 25:00
数字分别代表距离回合休息还剩5回合、距离时间休息还剩25分钟。
两项都开时同时显示，任意一项先到就触发；关闭一项就隐藏对应数字。
回合显示0表示结束当前回合时休息。鼠标悬浮显示完整说明，点击打开设置。
无操作满1分钟，入口原位显示“已休息 X 分 Y 秒”，恢复操作后恢复图标数字。
两项都关闭时，保留一个“已关闭”的设置入口。

按回合休息
读取游戏自身的回合数。第0回合只是起点，第5回合结束时首次休息。
固定每20回合一档，不可修改分档宽度：
  1–20 回合：每5回合。
  21–40 回合：每4回合。
  41–60 回合：每3回合。
  61–80 回合：每2回合。
  80 回合之后：每回合。
没有其他休息打断时，默认休息回合为：
5、10、15、20；24、28、32、36、40；43、46、49、52、55、58；
62、64、66、68、70、72、74、76、78、80；81及以后每回合。
每档间隔仍可调整1–100回合；不会追溯、累计跨时代回合。

按时间休息
默认连续游戏25分钟强制休息5分钟，无需等待结束回合。
短暂不操作仍计入本次连续游戏时间；连续无操作满5分钟视为休息一次。
鼠标移动、点击、滚轮、键盘、触摸及手柄导航均算游戏内操作。
空闲满5分钟后计时保持为0，恢复操作时重新开始，离开更久不会重复弹锁。
此空闲判定属于按时间休息功能，关闭按时间休息后也关闭空闲自动重置。
游戏内读档、切换存档的加载等待时间计入连续游戏时间，不被误算成空闲休息。
返回主菜单再加载也保留本次计时。完整退出游戏后清零，下次启动重新开始。
连续游戏上限可设1–240分钟；每次休息可设0.1–120分钟。默认两项都开启。

共同重置
两种功能只有触发条件不同；完成任何一次强制休息或5分钟空闲休息，
都会同时重新计算本次游戏时间和距离下一次回合休息的间隔。
例如本来第5回合该休息，第4回合因时间限制休息后，下一次回合休息移至第9回合。
跨过20回合分界时仍按新档位计算，不改变固定分档。两项同时到期只休息一次。
强制休息到时后点击“休息完成，继续”；若由过回合触发，继续先前的过回合操作；
若由时间触发，恢复当前游戏，不自动推进回合。

安装与使用
退出游戏后双击 install.cmd，或运行 install.ps1。
安装到 %LOCALAPPDATA%/Firaxis Games/Sid Meier's Civilization VII/Mods/civ7-rest-guard。
游戏附加内容中启用“休息一下 · Rest Guard”，载入单人存档即可。
右上角点击设置，分别开启/关闭两项，调整参数后点击保存。
休息过程中无法修改设置，Escape不能关闭锁；切换到其他窗口仍计入休息时间。
多人及热座不启用，不修改原版文件或游戏存档。

数据与升级
长期只保留设置，不建立战役或回合历史。为满足读档续计时，切换界面时会写入
一份临时交接状态（当前计时、当前休息及上一次休息位置），目标界面读取后立即清除。
正常游戏中的计时和输入不会持续保存回合或倒计时；重新启动不恢复上次游戏时间。
旧版本代码自动备份到 ModUserData/RestGuardBackups；升级保留已有时长及间隔。
禁用Mod即可停止生效。1.2新增的时间功能默认开启，可以单独关闭。

ui/rest-session.js：两类触发、空闲检测、共同重置。

ui/rest-guard.js：游戏输入和过回合拦截。
ui/rest-view.js / rest-guard.css：中文设置、倒计时、右上角原版图标。

1.3界面：直接复用原版 fxs-frame、fxs-header、fxs-button、fxs-switch；设置与休息锁使用官方深蓝金色边框和按钮。入口与原版系统栏同排，空闲提示不向下覆盖领袖头像。
